# Timbre

Apple Mail for AI assistants, on your Mac: every account, searched in
milliseconds, read safely, every change undoable.

**Presentation, installation and privacy policy:
https://alejandrosml.github.io/timbre/**

This repository only holds the files of the latest version, under
[Releases](https://github.com/alejandrosml/timbre-download/releases/latest).
They are signed with a Developer ID and notarized by Apple, for Intel and
Apple Silicon.

Timbre is open source, under the [MIT licence](LICENSE): each version comes
with the archive of its source code, `timbre-X.Y.Z-source.zip`, among those
files. Questions: asml@laposte.net.
